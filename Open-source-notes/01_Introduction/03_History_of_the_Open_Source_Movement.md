# History of the Open Source Movement
---
## Why study the history?
Understanding the history heps answer questions like:
- Why was Open Source created?
- Why do GPL, MIT, Apache and BSD license exist?
- Why do we have Linux today?
- Why are Richard Stallman and Linus Torvalds important?
---

## Before Open Source (1960s-1970s)
In the early days of computing:
- Universtiies freely shared software
- Programmers exchanged source code
- Collaboration was common
- Software was viewed as a complement to hardware, not a separate product
Example: IBM often sold hardware, and software came along with it
---
## The shift toward proprietary software (Late 1970s-1980s)
As the software industry gave, companies realized software itself could be sold, changes included:
- source code became hidden
- modification was prohibited
- redistribution became illegal
- Licenses became restrictive
---
## Richard Stallman and the GNU Project (1984)

### Who is Richard Stallman?
He is a programmer and software freedom activist, he believed users should have the freedom to use sw, study it, modify it and share it
To promote these freedom he started the GNU Project in 1984

### What is GNU?
GNU stands for: GNU's not Unix
It was intended to create a free operating system compatible with Unix
The GNU project developed many essential tools, including:
- GCC (GNU compiler collection)
- Bash shell
- GNU Core utilities
- GDB Debugger
However, it still lacked one crucial component: THE KERNEL

### Free Software Foundation (FSF)
In 1985, Richard Stallman founded the FSF, its goals were:
- promote software freedom
- support free software development
- publish open-source licenses
- protect user rights
The FSF also introduced the GNU General Public License (GPL)

### GPL Version 1 (1989)
The first GPL license was released in 1989
Its purpose was to ensure that software remained free for future users
Key Idea:
    If you distribute modified GPL software, you must also provide the source code under the GPL
This concept is known as Copyleft

--- 
## Linux Torvalds and the Linux Kernel(1991)

### Who is Linus Torvalds?
He was a Finnish computer science student, in 1991 he developed a Unix like OS kernel as a personal project

### What is a kernel?
The kernel is the core part of an Operating System
It manages :
- CPU
- Memory
- Storage
- Devices
- Processes
Without a kernel, an operating system cannot function

### GNU + Linux = GNU/Linux
The GNU project had: Compiler, shell, utilities but lacked a kernel
Linus Torvalds created the Linux Kernel
Combining the GNU tools with the Linux kernel produed the complete operating system commonly referred to as Linux or GNU/Linux

---
## Red Hat (1994)
In 1994, Red Hat was founded to provide commercial support for Linux
This demonstrated that: **Open source software can also be a successful commercial business**
Today, companies often pay for:
- support
- security updates
- enterprise tools
- consulting
rather than the software itself

---
## Apache Web Server (1995)
A community of developers began building the Apache HTTP Server in 1995
Apache became one of the most widely used web servers in the world, for many years a large percentage of websites ran on Apache

---
## "The Cathedral and the Bazaar" (1997)
Eric Raymond published The Cathedral and the Bazaar in 1997
It compare two software development models:
1. Cathedral Model
- Closed development
- Small internal teams
- Infrequent releases

2. Bazaar Model
- Open collaboration
- Community contributions
- Frequent releases
- Public source code
Modern platforms like GitHub follow the Bazaar model

---
## Open Source Initiative (OSI) (1998)
The term "Open source" was coined in 1998 and the OSI was established
Its objectives include:
- Defining what qualifies as open source
- Approving open-source licenses
- Promoting open-soruce software worldwide
