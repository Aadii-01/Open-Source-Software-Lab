# Introduction to Open Source Software (OSS)
" What is Open Source ?"

## Definition
OSS is software whose source code is publicly available, allowing anyone to **use it, study it, modify it, redistribute it** under the coniditons of its license
Open source doesn't mean "no license" it means the software is distributed under an open source license that defines what you are allowed to do


## What is source code?
Source code is the human-readable plain text version of a computer program, written in a programming language by developers
When we install software like Chrome or Photoshop we don't get the source code usually, instead we get the compiled program
With OSS, the source code is available

## Why was Open Source Created?
Many developers believed making a software proprietary (source code hidden, modifications prohibited, redistribution illegal) made it a slowed innovation. Thus, the Free Software movement and later the Open source movement was created 

## Characteristics of OSS:
- Source code access
-Permission to modify
- Permission to distribute
- Community collaboration
- Transparency

## Real-world examples:

### Git

## Proprietary vs Open Source
| Feature                 | Proprietary        | Open Source            |
| ----------------------- | ------------------ | ---------------------- |
| Source Code             | Hidden             | Public                 |
| Modify                  | No                 | Yes                      |
| Redistribute            | NO                  | Yes (license permitting) |
| Community Contributions | Usually No         | Yes                    |
| Transparency            | Low                | High                   |
| Examples                | Windows, Photoshop | Linux, Git, Python     |


## Common misconceptions
### 1. Myth 1
Open source means free. That's wrong
Many open source products are sold commercially eg: RHEL, Gitlab enterprise

### 2. Myth 2
Anyone can do anything. That's wrong
Every open source project has a license, eg: MIT, Apache, GPL, BSD (These licenses define what is allowed)

### 3. Myth 3
Open source has no owner. That's wrong
Every project has copyright holders, eg: Python is open source byt Python Software Foundation owns the copyright
